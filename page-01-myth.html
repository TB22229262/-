COMMON FAILURE MODE

学不会通常不是因为懒，
而是你的学习系统没有反馈。

OBSERVATION // 收藏越多，完成越少 CORE SWITCH // 从情绪归因切到系统归因
多数人的学习系统，只有输入，没有检查点。

OLD FRAME

我不够自律，所以学不下去。

NEW FRAME

我没有把错误放到当天暴露。

快速诊断：你卡在哪里？

DIAGNOSIS情绪归因会继续增加内耗。把问题改写成一个可检查动作：今天学完后交付什么？谁能看？多久反馈？
DIAGNOSIS方向正确。下一步不是多收藏一条内容，而是立刻做一个小产物，让反馈发生。
HOOK你不是学不会，你是反馈太慢。
SETUP很多人把学习失败归因成懒、拖延、不自律。
TURN但真正的问题是：你学完以后，没有任何东西立刻告诉你错在哪。
